# NereidSphere 总览

NereidSphere 是 NereidAI 的轻量套件层：统一门户、单点登录（SSO）入口与统一 API 网关。它本身不包含任何产品业务逻辑。

## 在这里可以做什么

- 在 NereidSphere 登录页用套件账号**登录一次**。
- 从产品卡片**直接打开**已集成的产品而无需再次登录：NereidLink、NereidForge、NereidHorizon。
- 登录后可查看自己的**身份信息**——显示名称与角色。

## 产品卡片

每张卡片对应一个产品。会话有效时点击卡片会在新窗口打开对应产品，原窗口继续保留门户。内置产品描述和常见套件角色会随门户语言切换，参见
[通过单点登录打开产品](help:page/product-sso)。
